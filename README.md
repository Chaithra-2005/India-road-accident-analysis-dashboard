# 🚦 India Road Accident Risk & Safety Analytics Dashboard

A professional and interactive Power BI dashboard project focused on analyzing road accident data across India. This dashboard provides insights into accident severity, vehicle involvement, accident trends, high-risk areas, and major causes of accidents to support better road safety decisions.

---

# 📌 Project Overview

The **India Road Accident Risk & Safety Analytics Dashboard** is designed to help users understand road accident patterns using data visualization techniques in Power BI.

The dashboard transforms raw accident data into meaningful visual insights, helping identify:

* High-risk states
* Major causes of accidents
* Accident severity levels
* Vehicle-wise accident distribution
* Yearly and monthly accident trends
* Risk analysis and safety metrics

This project demonstrates the use of:

* Power BI Data Visualization
* Data Cleaning & Transformation
* Dashboard Design
* Risk Analytics
* Interactive Reporting

# 📈 Dashboard Insights

The dashboard provides the following analytical insights:

* Overspeeding is one of the leading causes of accidents.
* Maharashtra shows one of the highest accident counts.
* Cars contribute to the largest share of vehicle-related accidents.
* Fatal accidents represent a significant percentage of total accidents.
* Accident trends vary across different years and months.

# 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the `.pbix` file using Power BI Desktop.
3. Refresh the dataset if required.
4. Explore the dashboard using filters and visuals.
